# Security and Privacy

This repository is a public architecture edition derived from a private production system that processes sensitive personal wellness information.

Security and privacy take priority over reproducibility.

## Never commit

- API keys, bot tokens, OAuth secrets, passwords or private keys
- Telegram chat IDs, file IDs or private media references
- Live Google Sheets or document identifiers
- Webhook URLs or private infrastructure endpoints
- Names, personal profiles or identifying user attributes
- Health records, symptom histories or clinician-specific notes
- Private photographs or visual progress media
- Sensitive personal content from private wellbeing modules
- Production prompts containing personal context
- Credential objects or full n8n production exports
- Proprietary production state snapshots

## Public architecture policy

The repository may document:

- system boundaries
- module responsibilities
- state-machine concepts
- generic schemas
- decision ordering
- failure modes
- safety and privacy controls
- production-scale counts that do not identify a person

## Reporting a concern

If you notice information that appears sensitive, avoid reposting it publicly.
